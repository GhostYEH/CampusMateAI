# 综合测评材料说明

> 演示资料，并非用户所在学校的真实现行制度。正式参与综合测评前请以学院当年发布的实施细则为准。

## 一、综合测评组成

本科生综合测评总分 100 分，由四个部分加权构成：

1. 学业成绩(60%)：本学年所有课程加权平均分。
2. 思想品德(15%)：班级评议 + 班主任评价 + 辅导员评价综合。
3. 社会实践(15%)：志愿服务时长、社团活动、社会实践学分认定情况。
4. 创新创业(10%)：学科竞赛、科研立项、论文、专利、创业项目。

## 二、所需材料清单

每学年综合测评开始前，学生需向班级综合测评小组提交以下材料：

### 学业部分
- 本学年成绩单(从教务系统导出，加盖学院章)。

### 思想品德部分
- 思想品德自评表(本人填写并签字)。
- 班级评议记录(由班级综合测评小组填写)。
- 班主任与辅导员评价意见(密封件，由评价人直接交给综合测评小组)。

### 社会实践部分
- 社会实践学分认定证明(由学院教务办出具)。
- 志愿服务时长记录(从校青协系统或志愿北京平台导出)。
- 社团活动担任干部证明(由社团联合会盖章)。

### 创新创业部分
- 学科竞赛获奖证书复印件(需出示原件核对)。
- 科研立项结题证明(由指导教师签字)。
- 已发表论文的期刊封面、目录与正文复印件。
- 专利受理或授权通知书复印件。
- 创业项目登记证明(由创新创业学院盖章)。

## 三、办理流程

1. 班级综合测评小组发布通知后，学生在 5 个工作日内提交材料。
2. 班级综合测评小组初步审核材料完整性与真实性。
3. 班级综合测评小组计算个人综合测评总分并公示。
4. 公示期 3 个工作日，学生可对结果提出复核申请。
5. 学院综合测评工作领导小组复核后正式生效。

## 四、办理地点与提交方式

- 学业材料：班级综合测评小组组长处。
- 思想品德材料：班主任处。
- 社会实践与创新创业材料：班级综合测评小组组长处(汇总后交辅导员)。
- 最终汇总：辅导员办公室，行政楼 312 室。

## 五、截止时间

每学年综合测评材料提交截止时间为开学后第 3 周周三 17:00。

## 六、注意事项

1. 所有复印件须本人签字确认与原件一致。
2. 材料一经提交不得修改，复核期间仅可补充说明。
3. 弄虚作假一经查实，取消当年综合测评资格并通报。
4. 同一成果不得在多个部分重复计分。

## 七、相关加分细则(参考)

- 国家级竞赛一等奖加 3 分，二等奖加 2 分，三等奖加 1 分。
- 省级竞赛一等奖加 2 分，二等奖加 1 分，三等奖加 0.5 分。
- 中文核心期刊论文加 2 分，普通期刊论文加 0.5 分。
- 志愿服务每 10 小时加 0.5 分，上限 3 分。
