# 大学英语四六级考试报名须知

> 演示资料，并非用户所在学校的真实现行制度。具体报名时间、费用与要求以学校教务处当年发布的通知为准。

## 一、考试时间

全国大学英语四六级考试（CET-4 / CET-6）每年举行两次：

1. 上半年：6 月中旬（具体日期以教育部公告为准）。
2. 下半年：12 月中旬（具体日期以教育部公告为准）。

## 二、报名条件

1. 在校全日制本科生及研究生。
2. CET-4 成绩达到 425 分及以上方可报考 CET-6。
3. 已通过 CET-6 的学生不可重复报考同一级别。

## 三、报名流程

1. 登录全国大学英语四六级考试报名网站（cet-bm.neea.edu.cn）。
2. 注册账号并填写个人信息（姓名、学号、身份证号、照片）。
3. 选择考点（原则上为本校考点）。
4. 在线缴纳报名费（CET-4 / CET-6 每科 30 元）。
5. 确认提交，等待考点审核。
6. 审核通过后，考前一周内打印准考证。

## 四、截止时间

报名截止时间一般为考试前 30 天左右，具体以报名网站公告为准。逾期不再补报。

## 五、所需材料

1. 本人有效身份证件。
2. 近期免冠证件照（白底，JPG 格式，分辨率不低于 144×192）。
3. 银行卡或支付宝（用于在线缴费）。

## 六、注意事项

1. 报名信息一经提交不可修改，请仔细核对后再确认。
2. 缺考考生当次成绩记为 0 分，不影响下次报考。
3. 准考证遗失可在报名网站重新打印。
4. 成绩发布后可通过报名网站查询，成绩单由学校统一发放。

## 七、联系方式

- 校内咨询：教务处考试中心，行政楼 203 室。
- 电话：以学校当年通知为准。
