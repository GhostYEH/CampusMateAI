# 活动报名常见问题

> 演示资料，并非用户所在学校的真实现行制度。具体活动报名细则以活动通知原文为准。

## 一、活动类型

校内活动主要分为以下几类：

1. **学术讲座类**：邀请校内外学者开展的学术报告、专题讲座。
2. **文体活动类**：包含文艺演出、体育比赛、社团展示等。
3. **志愿服务类**：校内志愿者岗位、社区服务、公益活动等。
4. **竞赛类**：学科竞赛、创新创业大赛、技能比赛等。
5. **培训类**：技能培训、生涯规划讲座、心理工作坊等。

## 二、报名渠道

校内活动通过以下渠道报名：

1. **校园活动管理平台**：主要报名入口，支持在线报名与签到。
2. **学院通知群**：班级 QQ 群、微信群内辅导员转发。
3. **社团系统**：仅限社团内部活动报名。
4. **线下报名**：少量活动需到指定办公室登记。

## 三、所需材料

一般活动报名无需提交材料，以下情况除外：

1. **竞赛类活动**：需提交报名表、指导教师推荐意见、作品初稿(部分)。
2. **志愿服务类**：需提供身份证复印件、健康承诺书。
3. **外出活动**：需提交家长知情同意书、安全责任书。
4. **跨校活动**：需由学院出具推荐意见并加盖公章。

## 四、报名流程

1. 登录校园活动管理平台。
2. 在活动列表中查找目标活动。
3. 阅读活动详情、时间地点、报名要求。
4. 点击"立即报名"，填写报名信息并提交。
5. 系统自动发送报名成功通知至校园邮箱与手机短信。
6. 活动前 24 小时再次推送提醒。

## 五、注意事项

1. 每场活动容量有限，报满即止，部分活动开放候补。
2. 报名成功后无故缺席累计 3 次，将进入"活动失信名单"，本学期内不可报名活动。
3. 因故无法参加须提前 24 小时在系统中申请取消。
4. 部分活动需收取押金或工本费，活动结束后按规则退还。
5. 报名信息须真实，冒名顶替一经查实取消资格并通报。

## 六、学分认定

1. 学术讲座每场认定 0.5 个第二课堂学分，每学期上限 3 学分。
2. 文体活动参与每场 0.2 学分，获奖另加 0.5 至 2 学分。
3. 志愿服务按小时计算，每 10 小时 1 个学分，每年上限 6 学分。
4. 学分由活动主办方在活动结束后 5 个工作日内统一录入。

## 七、常见问题

1. **报名后未收到通知怎么办**：登录系统查看"我的报名"，若显示"已确认"即代表报名成功，通知延迟属正常。
2. **活动取消是否补办**：由活动主办方决定，通常顺延至下一场次或全额退还费用。
3. **迟到能否参加**：开场 15 分钟后停止签到，视为缺席。
4. **证书遗失如何补办**：联系活动主办方申请补办，需提供学号与活动名称。

## 八、联系方式

- 校园活动管理平台技术支持：校园信息化中心。
- 学生活动咨询：校学生会办公室，大学生活动中心 201 室。
- 学分认定咨询：校团委，行政楼 601 室。
