# 课程补退选流程

> 演示资料，并非用户所在学校的真实现行制度。具体时间与流程以学校教务处当年发布的选课通知为准。

## 一、适用对象

全校全日制本科生(含中外合作办学项目学生)，研究生选课按研究生院规定执行。

## 二、选课阶段

每学期选课分为三个阶段：

1. **初选阶段**：学期第 16 周周一 8:00 至周三 17:00，所有学生可选下学期课程。
2. **补退选阶段**：下学期开学第 1 周周一 8:00 至周五 17:00，可补选、退选。
3. **最终确认阶段**：下学期第 2 周周一 8:00 至周三 17:00，仅可退选不可补选。

## 三、可选课程类型

1. **必修课**：由系统自动预置，无需手动选择，但可在补退选阶段查看班级调整。
2. **专业选修课**：由学院教务办公室在系统中开放，需手动选择并满足先修课程要求。
3. **通识选修课**：包含人文社科、自然科学、艺术审美、身心健康四类，每类需修满规定学分。
4. **体育选项课**：按项目分类，每学期可选一项，先到先得。

## 四、操作流程

1. 登录教务管理系统。
2. 进入"选课管理" - "选课入口"。
3. 选择相应阶段(初选/补退选)。
4. 按课程类别筛选可选课程。
5. 点击"选择"按钮，确认后提交。
6. 退选操作：进入"我的课表"，点击课程右侧"退选"按钮并确认。

## 五、注意事项

1. 每学期选课总学分不得超过 28 学分(含必修)，最低不得低于 16 学分。
2. 通识选修课每学期最多选 2 门，四年内需修满 8 学分。
3. 同一教学班容量上限为 120 人，体育选项课上限为 30 人。
4. 退选后该课程不显示在成绩单中，但补退选阶段结束后无法再退选。
5. 先修课程未通过者，不得选修后续课程，违规选修的成绩不计入成绩单。
6. 退选体育选项课后下学期需重新选择，未选择者由体育学院随机分配。

## 六、办理地点

- 在线办理：教务管理系统(校内访问或 VPN)。
- 现场咨询：教务处学籍科，行政楼 502 室。
- 技术支持：信息中心，行政楼 100 室。

## 七、常见问题

1. **课程容量已满怎么办**：可加入"候补队列"，系统在有学生退选时自动按顺序补入。
2. **跨专业选修如何申请**：需提交《跨专业选课申请表》并由双方学院教务办签字确认。
3. **选错课程能否撤销**：在补退选阶段内可自行退选，无需审批。
4. **体育选项课项目冲突**：每学期每人仅可选一个体育项目，重复选择系统会自动拒绝。

## 八、特殊情况

因生病、参军、交流学习等特殊原因无法在规定时间内选课者，需在开学第 2 周内向学院教务办提交书面申请，附相关证明，由学院教务办代为操作。
