# 待办与专注自习界面重做设计

## 目标

在现有 Android Jetpack Compose 校园应用中，复刻用户提供的两张移动端参考图：`待办` 仪表盘与 `专注自习` 番茄钟。两页必须保留原有数据和核心能力，并将参考图中可触达的内容实现为同一视觉系统下的可用二级界面。所有业务数据以已认证用户的后端数据库记录为唯一事实来源；界面不得生成、混入或持久化演示数据。

## 视觉系统

- 浅雾白背景搭配冷紫蓝渐变光晕；页面主体采用 20–28dp 圆角白色卡片、低对比阴影与细描边。
- 主色为高饱和靛蓝到紫色渐变；成功为翠绿、临期为珊瑚橙。标题为深靛蓝，正文使用蓝灰。
- 各页面沿用应用的无障碍文字缩放、减弱动态效果和底部导航预留空间。

## 待办

### 首页

- 顶部显示标题、说明和运行模式标签；统计卡展示今日待办、临近截止、已完成、全部任务及环形总体进度。
- 显示一周日期条、日历入口、搜索框、筛选入口和分类 Chips。
- 智能聚焦卡突出最优先任务，提供“去专注”入口，并呈现预计时长与进度。
- 下方以“今日重点”“即将到期”“今日课程”“AI 助理建议”组成双栏信息区；窄屏时自动改为单列。
- 悬浮新增按钮打开任务编辑底部抽屉；勾选任务、删除任务、搜索和筛选直接更新显示数据。

### 二级流程

- 点按任务卡进入既有任务详情页；详情保留编辑、完成状态和删除能力，视觉对齐新版。
- 点按日历入口进入日历视图，可按日期查看任务并返回待办首页。
- 点按“去专注”带入任务标题进入专注页；点按“查看全部”切换到任务的全量视图。

## 专注自习

### 首页

- 顶部使用返回按钮、标题和说明；主卡提供 25 分钟专注、5 分钟短休息、15 分钟长休息三种模式。
- 中心为带微点刻度的环形倒计时，开始后切换为暂停与结束；计时、完成记录与恢复以服务端会话为准。
- 学习状态辅助卡保留本地处理、摄像头权限和模型状态；状态信息使用参考图的分行信息结构。
- 统计卡显示今日分钟数、完成次数、连续天数。自习目标卡显示从服务端读取的每日目标及“设定目标”入口。

### 二级流程

- “设定目标”打开目标编辑抽屉，提供 30/60/90/120 分钟并立即提交到后端数据库。
- 结束专注显示确认弹窗；完成后显示完成反馈。学习辅助开关遵循既有权限流程。
- 来自待办的“去专注”会在专注页显示关联任务，不创建第二套计时器。

## 服务端数据与业务边界

- 以 JWT 身份标识当前用户；客户端只请求当前账号的数据，服务端继续执行任务和学习会话的 `user_id` 隔离，跨用户 ID 一律不可读写。
- 待办首页和详情页从现有 `GET /api/v1/tasks` 与 `GET /api/v1/tasks/{taskId}` 获取；创建、编辑、完成、恢复和软删除分别使用现有的 `POST`、`PATCH`、`complete`、`restore`、`DELETE` 接口。统计、日期、临期、优先级和筛选只由接口响应实时派生，不能写死截图中的数量或文案。
- 课程和活动区域从现有课程、活动接口取得，并显式处理空列表；AI 建议仅在服务端返回的真实任务与截止时间基础上计算或调用已有受控服务。
- Android 端新增学习会话 DTO 与 Retrofit 调用，接入已有 `POST/GET /api/v1/study/sessions`、`active`、`pause`、`resume`、`finish` 接口。点击开始后先成功创建服务端会话，才开始 UI 倒计时；暂停、恢复、结束均以服务端返回的状态和服务端计算的时长为准。
- 当前 `FocusRepository` 的本地 `FocusSnapshot` 不再作为业务记录或统计来源。它最多作为未提交操作的瞬态恢复信息；应用恢复、页面重入及网络重连时须读取 `GET /study/sessions/active` 与历史会话，再由服务端记录重新计算计时、统计和连续天数。
- 每日自习目标需要补齐后端能力：新增用户隔离的 daily-study-goal 表、迁移、repository、`GET /api/v1/study/goals/daily` 和 `PUT /api/v1/study/goals/daily`。服务端校验目标范围 15–480 分钟；客户端只在收到成功响应后更新界面。
- 网络、401、422、404、409 与 5xx 必须展示明确的加载、空态、错误和重试状态。写操作失败不伪装成功：保留原界面数据、显示错误，并提供重试；服务端成功后再刷新权威数据。刷新失败时可展示上一次已确认的数据和“数据可能已过期”提示，但不生成本地任务或专注记录。

## 导航与模块边界

- 复用 `AppNavHost` 中现有 `tasks`、`task_detail/{taskId}`、`focus` 路由及 repository；新增页面仅增加与这两个流程直接相关的路由。
- 不改动通知、个人中心、教师端及工作区现有未提交文件。
- 将待办和专注的远端 DTO、映射、状态机与 Compose 组件分别隔离，避免 UI 直接调用 Retrofit 或写入数据库。

## 验证

- 为任务、会话和目标的 DTO 映射、状态转换、失败回滚及路由参数增加/更新 JVM 测试；UI 通过 Android 构建和现有测试集验证。
- 为新增每日目标接口增加数据库迁移、用户隔离、范围校验与 CRUD 的后端集成测试；对既有任务和学习会话 API 增加端到端写入后再读取的测试，验证记录确实落库且只对创建者可见。
- 在可用模拟器或预览中对照两张参考图，检查 360dp 宽度下的间距、卡片层级、文字溢出、底部导航间距和关键可点击流程。
