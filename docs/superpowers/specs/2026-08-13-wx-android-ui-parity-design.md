# 微信小程序安卓界面对齐设计

## 目标

以当前工作区中正在运行的安卓学生端为唯一视觉基准，在不修改安卓代码、不改变小程序现有业务能力的前提下，对齐微信小程序现有八个页面。

## 范围

- 主页面：首页、课程、待办、AI 校园助手、我的。
- 二级页面：登录、校园通知、学习与专注。
- 公共界面：颜色、文字、圆角、卡片、按钮、输入框、状态标签、悬浮底栏、深色模式和减少动态效果。
- 保留现有 Mock/真实后端切换、登录、待办增删改、通知提取、聊天和计时功能。
- 安卓端已有但小程序尚无的考试、空教室、办事大厅、失物招领等独立模块不在本次新增范围内；首页入口不伪造不可用页面。

## 视觉基准

- 主色：`#5B68F2`；主色深态：`#4E5EDB`；柔和底色：`#EFF0FF`。
- 页面背景：`#F6F8FA`；正文：`#1B2730`；次级文字：`#667784`；描边：`#E2E7EC`。
- 卡片以 24–30rpx 圆角、细描边和极轻阴影为主。
- 底栏为左右留白的悬浮圆角容器，当前项使用淡紫底、紫色图标与文字，并保留待办角标。
- 信息层级、模块顺序、留白密度以 1280×2856 安卓实机截图为准，并对微信状态栏和胶囊按钮做平台适配。

## 页面设计

### 首页

采用“个人入口 → 考试周横幅 → 五个快捷服务 → 今日课程 → 学习总览/近期截止”层级。小程序已有课程、待办、通知和专注交互继续可用；没有对应页面的安卓快捷服务明确反馈“功能建设中”。

### 课程

采用大标题、模式状态、下一节课主卡、周日期条、四项统计、筛选项和单列课程卡。课程卡显示课程名、教师、时间地点和类型，沿用现有课程数据。

### 待办

采用大标题、汇总卡、日期条、搜索与筛选卡、智能聚焦卡、任务列表和悬浮新建按钮。保留完成、删除、新建与筛选行为。

### AI 校园助手

采用大标题、机器人介绍卡、两列建议问题、聊天消息和固定输入区。保留建议问题、发送中状态和引用说明。

### 我的

采用紫色身份头图区、四项快捷入口和“更多服务”列表。现有设置全部收进页面内的设置面板，避免丢失 Mock、深色模式、减少动态、提醒、后端地址与退出登录能力。

### 登录、通知、学习与专注

只做视觉系统统一与布局精修，保留现有业务结构；移除登录页依赖本地 HTTP 视频的脆弱背景，使用随包校园图作为稳定视觉资源。

## 状态与可访问性

- 保留加载、空、错误、禁用、发送中、计时中、暂停和完成状态。
- 点击目标不小于 80rpx；输入框与按钮有明确聚焦/按压状态。
- 深色模式使用安卓同源的蓝绿色夜间色板；开启减少动态后停用进入动画和闪烁效果。

## 验收

- `npm run typecheck` 通过。
- 交互处理器检查通过。
- 视觉契约测试确认主色、页面骨架和底栏结构。
- Git 路径差异证明本次未修改任何 `android/` 文件。
- 能启动微信开发者工具时，使用同状态截图对照；工具不可用则明确记录视觉 QA 阻塞原因。
