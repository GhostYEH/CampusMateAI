# Web 专注界面二级体验设计

## 范围

仅扩展 Web 端 `/study`，覆盖沉浸计时、AI 学习路线、指标洞察、历史复盘、趋势分析和任务编辑六类二级体验，不修改 Android、Harmony、微信端或后端接口。

## 交互架构

所有二级体验使用统一动态层：从主页面入口打开，支持遮罩点击、关闭按钮和 Escape 退出。主页面保持参考图的低干扰信息密度，复杂操作在动态层内完成。

- 沉浸计时：模式切换、通知/声音开关、开始、暂停、继续、结束。
- AI 路线：编辑目标、调用现有拆解接口、分步时间线呈现。
- 指标洞察：数据放大、七日节奏、解释性建议。
- 历史复盘：会话时长、目标、状态、感受与再次使用目标。
- 趋势分析：7/14/30 天切换、上期对比、悬停数据与汇总。
- 任务编辑：标题保存、带入目标、同步计划和真实完成操作。

## 动效语言

唯一主叙事是“卡片扩展为空间”：动态层使用裁切揭示和弹性位移；二级内容再按含义使用轨道呼吸、时间线错峰、柱形生长、印章落位、磁吸按钮和完成粒子。常态页面不放无意义循环动画。`prefers-reduced-motion` 下关闭动画与指针位移。

## 视觉与无障碍

沿用现有蓝紫校园品牌、Phosphor 图标与圆角规则。动态层使用 `role="dialog"`、`aria-modal`、明确标签、键盘焦点和移动端单列布局。
