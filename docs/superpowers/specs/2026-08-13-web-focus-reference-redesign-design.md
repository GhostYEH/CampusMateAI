# Web 专注页参考图重做设计

## 目标

在现有 Vue Web 客户端的 `/study` 路由内，严格按用户提供的 1678×941 参考图重做专注界面。保留已有学习会话、暂停/继续、结束记录、AI 任务拆解、统计、趋势与待办能力，不修改 Android、HarmonyOS、微信小程序、后端接口或其他 Web 页面。

## 视觉结构

- 保留现有学生端侧栏和顶栏组件，只在 `/study` 路由下通过 `study-mode` 作用域对尺寸、背景和间距做参考图匹配。
- 主内容最大宽度随工作区铺开，桌面端以参考图比例为基准。
- 页面首部仅保留大标题、副标题和星光图标，不显示额外刷新按钮或英文眉题。
- 第一行左侧为专注主卡，右侧为学习计划卡；右侧下方紧接四项指标卡。
- 第二行依次为最近记录、专注趋势、待完成计划，比例接近参考图。
- 主卡使用现有 `campusmate-hero-illustration.png` 机器人图，不生成或修改其他客户端资产。

## 交互与数据

- 25、50、75 分钟和自定义时长仍可选择；开始、暂停/继续、结束并记录继续调用现有接口。
- 专注模式、阻止通知、环境声音控件保留并可操作。
- 学习目标可输入，示例目标可一键填充，AI 拆解继续调用现有接口。
- 最近记录、统计、趋势和待办继续使用当前服务端数据；空状态仍可从页面开始专注。
- 错误、加载和成功提示保留，但视觉融入新页面。

## 响应式与隔离

- 1678×941 为主要视觉验收视口。
- 中等桌面宽度下右侧卡片和底部区域保持可读，不出现横向溢出。
- 900px 以下沿用现有移动侧栏模式，专注页卡片改为单列；此处只做 Web 响应式，不修改原生客户端。
- 所有新增选择器以 `.study-reference` 或 `.study-mode` 为入口，避免覆盖其他页面。

## 验收

- 增加源码级回归测试，验证参考图核心结构、交互绑定、独立样式引入和 `/study` 壳层作用域。
- 运行 Web 测试与生产构建。
- 在同视口捕获页面截图，与参考图并排检查布局、间距、字体层级、卡片边框、主视觉位置和响应式；P0-P2 差异修正后才交付。

## 范围外

- 不修改后端、Android、HarmonyOS、微信小程序或教师端。
- 不新增路由、不重做其他学生端页面、不改变学习数据模型。
