# 启动提示词

> **使用方式**：把下面「提示词正文」整段复制给 Codex / GPT。
> 复制前把正文第一行的 `【参考项目根目录】` 替换成实际路径
> （参考项目是 OpenMAIC v1.0.x 的源码目录，只读）。
> 之所以用占位符，是因为仓库规则（`AGENTS.md`）禁止把本机路径写进提交物。

---

## 提示词正文

```text
参考项目根目录 = 【参考项目根目录】

你接手一个已经在进行中的前端移植任务，仓库就是你当前的工作目录。

第一步：把 `docs/openmaic-migration/` 这个目录里的全部文档读完。
入口是 README.md，它会告诉你其余文档分别是什么、什么时候读。
其中 01-约束.md 与 04-陷阱.md 是动手前必读；03-待办.md 是你要做的事；
06-参考实现地图.md 告诉你参考项目（上面那行给出的目录）的对应文件在哪。

读完之后，按 03-待办.md 的优先级从第一项开始，按切片推进：
一个切片做完就提交一次，并且必须用真实浏览器（Playwright，不许 mock 后端）验收，
把几何/文本的实测值与 pageerror、console error 的具体条数作为证据给我。
验收口径见 05-工程规范.md。

三条硬约束（文档里有详细版，这里先划重点）：

1. 不要违反架构边界：浏览器只调 CampusMate API，不得直连 :4010，不得引入第二套
   登录/导航/课程库，不得把产品外壳放进 iframe。
2. 参考项目是只读的：可以读它的源码做对齐依据，但不要修改它，不要把它的大体积
   二进制资源拷进仓库（那要走 third_party/ 的 LICENSE / NOTICE / SHA 清单流程）。
   不要把它的路径写进任何提交物。
3. 能力缺失时不要假装：没有对应运行时的功能（例如 PBL workspace 阶段、圆桌的
   流式与逐智能体 TTS）不要渲染入口，也不要放点了没反应的死按钮。保持显式占位，
   并在交付说明里写清楚。

先跑 `node scripts/openmaic-local.mjs start` 起三服务，用 student_demo / Demo123456
登录 http://127.0.0.1:5174/courses 点「进入课堂」把现状看一遍，再开始改。

注意：这台开发机有 WHEA 硬件报错史（Windows 事件日志里出现过 0x124
WHEA_UNCORRECTABLE_ERROR 与 0x7E）。跑浏览器验收时用单实例、只加 --disable-gpu；
不要同时加 --disable-software-rasterizer，那会导致页面完全不绘制、元素判定为不可见。
若机器再次蓝屏，先看 %SystemRoot%\Minidump\ 里的转储。

现在开始：先告诉我你读完文档后的理解，以及第一个切片的计划。
```
