## 优先级 3 · 更多幻灯片版式

`title`（纯标题）/ `bullets`（要点）/ `sections`（2~3 张卡片）。

补：封面页、目录页（编号列表）、双栏对比、要点+结论条。
**约束**：合成必须是纯函数且确定性，几何不变量（元素在画布内、页眉不与正文重叠、
id 唯一、文本自带内联字号）必须继续被 `tests/slide-canvas.test.mjs` 钉住。
