### 新增的 DSL 合成与投影

| 文件 | 职责 |
| --- | --- |
| `src/dsl/slide-canvas.ts` | 幻灯片画布合成器（3 种确定性版式）+ `upgradeLegacySlideCanvases` 读时投影 |

| `src/workspace/repository.ts` | `getStage` 是所有读路径的**唯一咽喉**，投影挂在这里 |

**投影的三条边界**（改之前务必守住）：只补确实缺失的；无改动返回同一引用；
不注入时间戳（否则读一次就"变"一次，幂等与"没变就不重写"都失效）。

### 关键契约

- `src/dsl/contract.ts`：Scene / Stage / Action / QuizQuestion 等形状。
- `src/dsl/validate.ts`：`prepareStage` = migrate → bound → sanitize → validate。
- `src/generation/generator.ts`：本地模板 + `materializeGeneratedStage`（把模型输出
  变成可落库的聚合，服务端分配所有 id 与时间戳）。
- `src/provider/client.ts`：提示词在这里。**改生成形状要同时改提示词与合成器。**
