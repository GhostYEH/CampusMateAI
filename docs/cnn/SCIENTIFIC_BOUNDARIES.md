# 科学边界（强制）

本文件是 CampusMateAI CNN 面部表情识别工程的科学边界约束。所有协作者
（人类开发者与 AI Agent）必须遵守。这些约束与项目根目录 `AGENTS.md` 第 3 节一致。

## 1. 识别对象

本工程识别的是**可观察到的面部表情**，使用 FER2013 数据集的七类标签：

```
angry, disgust, fear, happy, sad, surprise, neutral
```

这是面部表情分类，**不是**：
- 人员身份识别
- 疲劳检测
- 注意力检测
- 心理状态诊断
- 心理疾病诊断

## 2. FER2013 不包含的类别（强制）

以下类别**不属于** FER2013，**禁止**作为本工程的分类结果输出：

- `fatigue` / `tired`（疲劳）
- `attention`（注意力）
- `anxiety`（焦虑症）
- `depression`（抑郁症）
- `stress`（压力）
- `mental_illness`（心理疾病）

代码层面，这些类别列在 [`constants.FORBIDDEN_OUTPUT_CATEGORIES`](../../ml/expression_recognition/expression_recognition/constants.py)，
用于校验与防范。

## 3. 表达约束

代码与文案中禁止出现：
- "检测出你患有焦虑症"
- "你现在一定很难过"
- "AI 已确认你的心理状态"
- "识别到你处于疲劳状态"（把疲劳当作 FER2013 分类结果）

应使用谨慎表达：
- "系统观察到当前表情可能偏低落"
- "识别结果仅供辅助参考"
- "你好像有些疲惫，需要休息一下吗？"（这是基于表情的温和建议，不是把疲劳当作 FER2013 类别输出）
- "最近任务是不是有些多？我们可以一起整理。"

## 4. 疲劳 ≠ FER2013 表情类别

疲劳判断不能由 FER2013 模型直接给出。若业务侧需要疲劳相关提示，需结合：

- 连续学习时长
- 用户主动填写的学习感受
- 后续闭眼/眨眼/头部姿态信号（独立于本工程）

本工程**不**输出疲劳类别。任何疲劳判断逻辑必须独立于 FER2013 分类模型，
并在产品文案中明确其依据与局限性。

## 5. 情绪陪伴边界

情绪陪伴只提供日常辅助，**不**进行疾病诊断，**不**替代专业心理咨询。
若用户出现持续严重情绪困扰，应引导其联系学校心理咨询中心或专业机构。

## 6. 低置信度处理

模型低置信度时显示："暂时无法稳定判断当前表情。"
且**不得**触发情绪安慰逻辑。这由 Flutter 端
`MockExpressionRecognitionService` / `LiteRtExpressionRecognitionService`
的置信度阈值与状态持续时间判断实现，本工程只提供模型与预处理契约。
