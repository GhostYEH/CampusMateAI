# CampusMate AI 比赛 Demo 流程

> 3-5 分钟现场演示脚本。每幕标注预计时长和关键验证点。

## 前置准备（赛前 5 分钟）

1. Backend 已启动，Demo 知识库已导入（9 份文档）
2. Web 已启动
3. Android Debug APK 已安装到真机
4. 真机已安装微信，通知权限已开启
5. 真机已登录 student_demo
6. Web 浏览器已登录 admin_demo
7. 另一部手机或电脑已登录微信，准备发送测试消息

---

## 第一幕：管理员上传知识（30 秒）

**场景**：管理员通过 Web 后台管理知识库

1. 展示 Web 管理员后台（/admin）
2. 进入知识库管理页面（/admin/knowledge）
3. 展示已有 9 份 Demo 文档
4. 点击上传新文档
5. 选择一份"校园羽毛球比赛报名须知.md"
6. 验证上传成功，列表刷新
7. 点击"重建索引"

**关键验证点**：管理员可以真实上传文档到知识库

---

## 第二幕：学生向 AI 校园助手提问（45 秒）

**场景**：学生通过 Android 向 AI 提问，验证 RAG 检索

1. 展示 Android 真机 → AI 校园助手
2. 输入：`奖学金申请需要哪些材料？`
3. 等待 AI 回答
4. 展示回答内容（应包含申请表、成绩单、综合测评证明、个人陈述等）
5. 展示引用来源（如"校级奖学金申请办法"）

**关键验证点**：AI 回答基于知识库真实资料，带引用来源

---

## 第三幕：通知捕获 → 解析 → 待办（60 秒）

**场景**：学生收到微信校园通知，CampusMate 自动捕获并解析

1. 从另一设备向学生微信发送：`数据结构实验三本周五23:59前提交到学习通`
2. 展示 Android 真机 → 通知中心
3. 验证通知已自动捕获，来源显示"微信"
4. 点击通知 → AI 解析
5. 验证解析结果：任务名"数据结构实验三"，截止时间"本周五 23:59"
6. 点击保存为待办
7. 切换到任务页
8. 验证待办已创建

**备选方案**（如真机通知无法稳定产生）：
- 在通知中心手动输入测试通知文本
- 点击解析按钮
- 后续步骤相同

**关键验证点**：通知 → 捕获 → 解析 → 待办完整闭环

---

## 第四幕：学习陪伴专注模式（60 秒）

**场景**：学生开启专注模式，展示 CameraX 和表情识别

1. 打开学习陪伴 → 专注模式
2. 授予摄像头权限
3. 展示摄像头预览正常
4. 展示表情识别标签（如 NEUTRAL / HAPPY）
5. 保持专注 30 秒
6. 展示学习时长统计
7. 退出专注模式
8. 验证摄像头正常释放

**关键验证点**：CameraX 正常工作，表情识别辅助学习陪伴，退出后摄像头释放

---

## 第五幕（可选）：通知过滤展示（30 秒）

**场景**：展示通知过滤能力

1. 从微信发送：`晚上吃什么？`
2. 从微信发送：`微信支付成功20元`
3. 打开 CampusMate → 通知中心
4. 验证以上两条均未出现在通知列表中（已被过滤）
5. 从微信发送：`英语四级报名截止时间为本周五17:00`
6. 验证该通知出现在列表中（校园事务被保留）

**关键验证点**：系统能区分聊天/支付与校园事务

---

## 赛后清理

1. 退出专注模式
2. 如上传了测试文档，在 Web 管理后台删除
3. 退出登录

## 注意事项

- 如现场网络不稳定，Backend 和 LLM 可能不可用。此时：
  - 通知仍可本地保存
  - AI 解析显示"服务暂时不可用"
  - 可手动创建待办
- 如真机通知无法在录屏环境稳定产生，使用备选方案（手动输入）
- 不要伪造系统通知捕获已完成
- Demo 知识库文档均标注"演示资料"，非真实学校政策
