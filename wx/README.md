# 微信小程序端

本目录是 CampusMate AI 的原生微信小程序，视觉和部分业务流程参照 Android 端。它以个人学习与事务为场景；AI 助手的产品定位是通用对话，但本端目前默认使用 Mock 演示。

## 已实现

- 学生演示账号登录
- 首页学习总览、课程预览、近期截止与快捷入口
- 课程分类筛选
- 待办新增、完成、删除、筛选与本地持久化
- 校园通知搜索、通知正文智能提取、保存到待办
- AI 助手对话与建议问题；Mock 模式下的知识库引用仅为演示
- 学习专注计时、主动感受记录、Mock 表情识别科学边界说明
- 个人中心、Mock/Real 模式切换、深色模式、减少动态效果
- 后端地址本机配置

## 运行

1. 使用微信开发者工具导入 `wx` 目录。
2. 小程序目录由 `project.config.json` 指向 `miniprogram/`。
3. 当前使用微信标准 WebView 渲染，以兼容页面中的 Flex/Grid 布局；如果开发者工具仍显示 Skyline，请重新打开项目并执行“清缓存 → 编译”。
4. 默认使用 Mock 模式。当前小程序仅支持学生端，演示账号为 `student_demo`，密码为 `Demo123456`。
5. 若接入真实后端，在“我的 → 真实后端”中配置服务地址，再关闭 Mock 模式。

真实后端地址不会写死在源码中，而是保存在微信本地存储。请求路径默认以 `/api/v1` 为前缀；本地调试需在微信开发者工具中按环境配置合法域名校验。

## 校验

```bash
npm install
npm run typecheck
```

小程序不具备读取同一手机上微信、QQ 系统通知或聊天记录的权限；通知整理以页面查看和手动输入为主。AI、知识库与表情识别的演示结果均明确标注为 Mock，不代表真实诊断或学校正式结论。切换到真实后端时，聊天仍会经过后端现有的检索链路，详见[主 README](../README.md)。
