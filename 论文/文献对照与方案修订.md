# 参考文献对照与方案修订

核查日期：2026-10-17。范围：用户放在 `参考/` 中的 12 篇 PDF，核查其标题／版本、摘要及与本题相关的方法、实验和限制；重点阅读 [L07]–[L10] 与 [L12]，并渲染查看关键公式、图表页面。此为定向文献分析，不是系统综述、算法复现或逐条定理的独立证明审计。

## 1. 结论与主线调整

原规划的工程基础仍然可用，但“冻结两级模型，通过后验风险校准决定是否调用后级”与 [L07]、[L10] 已有明显重叠。时间一致性不确定性也已有 [L09]。不能继续把这三个要素的组合直接当作方法新颖性。

更适合当前代码的待检验问题是：**当后级时序结果跨多个决策时刻复用时，如何决定旧证据继续使用、刷新或失效，并避免刷新后采纳有害结果？** 建议题目调整为“面向端侧行为识别的时序证据更新与风险校准”。这只是基于当前文献与代码提出的方向，不意味着该问题首次出现，亦不保证简单 TTL 或已有路由不能解决。

当前 [混合引擎](../android/app/src/main/java/com/example/campusai/data/behavior/HybridBehaviorRecognitionEngine.kt) 会缓存 `latestTemporalPrediction`，在未调用 TSM 时继续融合；还有八帧冷启动、`COMPUTER` 连续确认和回退清空。因此单次独立样本路由并不完全描述实际输出。可研究之处在这种状态依赖，而非将已有共形／早退出方法改名。

## 3. 最影响选题的四项发现

### 3.1 冻结后验风险控制已不是空白

[L07] §3.1 明确在固定权重上仅调整退出阈值；§3.2 分别定义有标签性能差和无标签一致性风险。§3.3 讨论期望／高概率控制以及 LTT。因此“冻结部署模型”“不用重训主干”“用风险而非手调阈值”不能单独形成差异化。新增必做对照是该思想在当前两级预测上的适配；不同抽样单位、缓存和非单调性须写清，不能直接引用其命题作为本方案定理。

[L10] §3.3 进一步给出两模型路由和联合阈值，正式 PMLR 题录与本地文稿标题一致。其目标是校准随机性与测试样本联合意义下的选择条件错误，不是某次校准后每个人物／每个时间段的条件保证。本文仅确认其报告内容与任务重叠，不代表独立验证全部证明。改变成视频路径后需要重新检查定义和条件。

### 3.2 时间一致性不能作为新信号，证据更新价值可以检验

[L09] 已将多滞后预测差异、特征相似、类别持续性和置信度组合成低成本信号。直接复制这些特征再加校准不够。可检验的增量是：相比只有当前置信度和短历史的门控，加入**旧 TSM 证据年龄、当前与已缓存证据的分歧、在线确认状态**，是否更好地判断何时刷新与失效。

先用简单年龄 TTL 排除容易解释的收益，再加学习门控。类别稳定既可能表示正确识别，也可能持续自信地出错；行为边界处预测变化也可能正常，不能一律当错误或漂移。真实错误需要独立标注评测，无标签在线阈值不自动恢复风险保证。

### 3.3 调用和采纳必须分开检验，但选择性修正本身已有先例

[L12] §V 与 Table III 显示：识别错误段的排序能力不等于能给出有益替换；无条件修正会损害序列质量，选择性采纳主要起到保护作用。它的证据不能证明本项目采纳门控一定有效，但要求我们报告调用致错、调用后拒绝、采纳率和无效计算。

该论文 §III 使用中心 16 帧特征和完整预测段序列的非因果注意力；§VI 明确列为离线设置。我们的候选策略只使用当时与历史信息，不能引入未来段标签、真实段长度或实际边界距离。后者只可用来事后分层分析。

### 3.4 覆盖、精度与系统效率的分母都要明确

[L12] §V 报告高覆盖同时集合接近全类别，说明高覆盖可能只来自信息量很低的大集合；§III／IV 还明确小样本阶数截断、稀有类回退及相关帧对形式保证的限制。本项目增加集合规模／空集／单元素／全集合比例，不能只画覆盖曲线。

[L01]／[L05] 提醒我们区分等待观察窗口与内核推理耗时。[L03] 的 DVFS 结果说明功耗模式是实验条件。借鉴这些测量维度，而不是搬用其性能数字或将额外传感器、在线重训和 DVFS 加到首轮范围。

## 4. 落到现有规划的修改

| 原方案 | 修订后的执行方式 | 主要依据 |
| --- | --- | --- |
| 风险校准的两级触发是主要候选贡献 | 降为既有方法基础，研究状态依赖的刷新／复用及实际收益 | [L07]、[L10] |
| 时间变化与置信度作为候选特征 | 标明已有信号，增加年龄／缓存状态并与其消融 | [L09] |
| 只决定是否调用 TSM | 分开调用、采纳与缓存失效，统计被拒调用成本 | [L12] 与当前代码 |
| 数据上先做片段，再考虑事件 | 真实连续转移数据是证据过期主张的前置条件；片段与合成流只做机制／压力测试 | 各论文任务差异 |
| 风险与效率的主要曲线 | 加入性能差 vs 绝对错误、集合信息量、年龄错误、转移段、等待时间和功耗状态 | [L01]、[L03]、[L05]、[L07]、[L12] |
| 大量完整论文复现 | 必做冻结骨干适配、TTL、学习门控；架构重建、在线 bandit、DVFS 与重训作为扩展 | 现有资源约束 |

## 5. 阅读与实现优先级

1. **先做重叠核查与最小对照：**[L07]、[L10]，确认与本项目风险／动作定义的对应关系。
2. **再做时间信号与有害修正诊断：**[L09]、[L12]，配合当前缓存链路，先测固定 TTL 和调用／采纳分离。
3. **系统测量：**[L01]、[L03]、[L05]，只采用可实现且可测的成本分解。
4. **扩展及相关工作：**[L08]、[L02]、[L06]、[L11]；[L04] 用于分类组织，不替代方法原文。

进入新方法开发前必须能回答：与 [L07]／[L10] 相比新增了哪个决策或状态？比固定 TTL 和相同输入的学习门控好在哪里？真实连续数据是否足以支持该差异？若回答不了，优先收窄方法，不扩大贡献措辞。
