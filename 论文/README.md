## 两个识别模块使用了什么技术

| 模块 | 当前实现 | 技术性质 |
| --- | --- | --- |
| 面部表情与三个状态标签 | ResNet18 共享主干；七类表情分支与三个独立状态输出；蒸馏、概率校准、四帧状态聚合 | CNN 与多任务学习，不是 Transformer |
| 行为单帧主模型 V3.4 | MobileNetV3-Small，在人物 ROI 上分类 | 轻量 CNN |
| 行为时序模型 V4 | MobileNetV2 + Temporal Shift Module（TSM），八帧时序确认 | CNN 加时序移位，不是 Transformer |
| 行为离线候选 | MobileNetV3 特征与 GRU 分支；局部区域双视图等实验入口 | GRU 是循环网络；候选入口不等于当前部署模型 |

“人脸识别”在本研究中应准确写为“面部表情识别”，不涉及人物身份识别。TSM 的 T 指 Temporal。LiteRT、ONNX Runtime、MindSpore Lite 是推理／转换相关技术，不是网络架构。

## 当前证据与发表差距

### 表情模型

本地已有 `ml/expression_recognition/artifacts/multitask_tuning_20261004/test/test_report.json` 与同级 `comparison.json`。这些是 Git 忽略的历史产物，其他克隆中可能不存在；下列数值是报告摘录，本次没有重新推理验证。

| 历史开发测试指标 | 数值 | 解释边界 |
| --- | --- | --- |
| 七类表情 Accuracy | 74.62% | 当前混合数据协议下的历史结果，不能直接与单数据集论文排名比较 |
| 七类表情 Macro-F1 | 0.6903 | 尚不能支撑方法领先的结论 |
| 三个状态平均 AP | 0.2151 | 原模型为 0.2126，增益较小，尚未证明稳定性 |
| 困惑正类 Recall | 3.85% | 校准概率按报告使用的 0.5 阈值计算 |
| 挫败正类 Recall | 0%，76 个正样本 | 同一阈值下全部漏检；95.68% Accuracy 来自全部预测为负，不能作为有效识别的证据 |

历史对照报告明确记录测试集此前已用于开发，且只使用一个训练种子。状态分支的阈值指标不能等同于手机界面的概率输出效果；零召回也不代表 AP 为零。后续若单独研究表情模块，应重新审计初始化权重接触过的数据、数据集划分、稀有类和校准表现。

### 行为模型

- 当前代码具备单帧与 TSM 的条件调用、类别融合、弃权和回退雏形。
- 当前触发项中的手机使用信号来自视觉预测 `PHONE_USE`；尚不能作为已接入触控、亮屏、IMU 或前台应用信号的证据。
- 现有大学课堂数据只有三个源视频前缀，人物身份未知。大量帧或裁剪不等于大量独立样本，不能证明人物独立泛化或前摄有效性。
- V4 模型卡缺少完整训练溯源；代码中的审计说明还记录了形状声明一致性问题。已有转换一致性不等于训练可复现或识别质量合格。
- 当前行为模块缺少可在本次会话中直接复核的完整训练／评测产物。不能填写成本占比、TSM 纠错收益、门控 AUC 或能耗节省等尚未测得的结果。
