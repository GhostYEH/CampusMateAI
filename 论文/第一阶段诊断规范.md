# 第一阶段诊断规范

更新日期：2026-10-17。状态：已按参考文件夹文献修订，待实现、待运行。此文档定义离线诊断的输入、输出、评价与继续／转向规则，不代表对应脚本、数据或结果已存在。文献编号 [L01]–[L12] 见 [文献对照与方案修订](文献对照与方案修订.md)。

## 1. 目标与边界

回答五个问题：现有策略还有多少可节省成本；TSM 何时纠错或致错；理想选择能带来多少收益；低成本信号能否预测调用价值；独立数据能否分辨预期收益。

本轮增加的重点：与已有无状态后验路由区分，诊断**旧时序证据的年龄、行为转移以及新结果采纳**是否影响调用价值。先比较简单 TTL 与相同骨干下的风险路由适配；不能仅以“冻结模型 + 共形阈值”作为方法创新。没有真实连续转移标注时，只做片段机制和人工压力测试，暂停自然事件级结论。

诊断先在开发数据上运行。未知旧权重接触范围的数据只能用于开发诊断，不能同时宣称独立验证。正式论文测试集不用于选信号、门控、阈值、运行点或继续／转向目标。

首版交付应复用 `ml/behavior_recognition/` 的模型读取、预处理和评价代码。新工具放入该模块现有代码／测试组织中；本目录只保存长期维护的规范。生成的预测、图表和报告使用 Git 忽略的 `artifacts/` 或 `reports/generated/`，不提交原始视频、日志及本机路径。

## 2. 拟定输入契约

这些字段是研究工具的拟定契约，不是当前后端或客户端 API。

### 2.1 数据索引

| 字段 | 类型与含义 |
| --- | --- |
| `sample_id` | 稳定且唯一的样本标识 |
| `dataset_id`, `source_video_id` | 数据源与原始记录标识，不能用文件夹数量替代独立视频数 |
| `subject_id`, `session_id`, `capture_group_id` | 人物、会话、同次动作多视角分组；未知时为空并说明 |
| `split` | 明确用途：训练、开发、校准或锁定测试 |
| `timestamp_ms` | 相对当前记录的时间戳，单位毫秒 |
| `label`, `label_scope` | 标签及其作用范围：帧、片段、事件或集合标签 |
| `event_start_ms`, `event_end_ms` | 仅真实时间标注存在时提供，不从片段标签伪造 |
| `annotation_status`, `quality_status` | 标注不确定与图像质量状态，区别于模型弃权 |
| `video_sha256`, `mapping_version` | 源记录完整性和标签映射版本 |

索引采用仓库／数据根目录相对路径或不含位置的标识；原始数据根目录由运行环境传入。研究分组应保持同一人物及同一采集记录不跨独立划分；无法满足时明确实验协议的实际边界。

### 2.2 预测缓存

每个可决策时刻记录单帧 logits、时序候选 logits、标签顺序、各自预处理版本、模型 SHA-256、时序窗口起止及所用帧标识。额外记录可用性、ROI 有效性、质量拒绝、推理失败与回退状态。

离线可预计算所有合法候选时刻的 TSM 输出以研究反事实，但在策略回放中，未触发时不能读取当前 TSM 输出或其派生特征。采用共享时间戳和单帧原有 ROI／TSM 原有输入约定，不能擅自统一成不同预处理。

增加独立于原始模型缓存的策略状态轨迹：`decision_at_ms`、`last_temporal_computed_at_ms`、`last_temporal_adopted_at_ms`、`temporal_evidence_age_ms`、`evidence_valid`、`action`、`adopted_new_temporal`、`rejection_reason`、`output_source`、`event_state`、`confirmation_emitted_at_ms`、`reminder_emitted_at_ms`。首次无证据时年龄为空；计算完成、决定采纳和事件确认不能共用一个时间字段。拒绝新结果后保留哪份缓存应在策略配置中固定。

`action` 拟定为 `retain`、`refresh`、`invalidate` 三类：保留当前路径、调用时序更新、拒用旧证据。`invalidate` 的结果按照预先声明的回退／弃权规则确定；它不是无代价的正确预测。每个策略生成自己的状态，不从另一策略轨迹拷贝缓存。

标签空间检查必须先执行：V3.4 为四类，V4 为五类。分别规定共有类别分析和包含额外 `COMPUTER` 的完整分析；单帧无此输出的能力限制必须显示，不静默删除额外类别。

### 2.3 成本测量

记录设备代号、运行时／版本、线程／加速设置、输入节奏、预热、重复、显示和温度条件。成本类别至少包含：共享采集或解码、ROI／预处理、单帧推理、帧复制与缓存、TSM 专属预处理及推理、门控和后处理。

分开报告计算量估计、累计处理耗时、端到端墙钟延迟和能量。未知项为空并附原因，不用零替代。没有设备功耗条件时不能用调用次数或桌面耗时冒充设备能耗。

借鉴 [L01]／[L05]，单列输入窗口等待、冷启动、解码／采集、排队、内核推理和确认输出等待；同一批视频必须按相同时间节奏回放，不能用离线极速加载与在线等待混比。借鉴 [L03]，记录功率模式／governor 和热状态，能量用 J 或每观察分钟能量表示，不用 W 冒充能量；无 DVFS 控制权限时不增加相关功能。

### 2.4 实验配置

配置需固定评价单位、类别集合、指标分母、预算网格、门控可见特征、分组划分版本、随机种子、状态初始化、冷启动、最大处理间隔、候选族、运行点决胜规则和统计比较。数值目标在预实验后、独立校准和最终测试前锁定。

## 3. 回放语义必须与当前链路对应

依据 [混合引擎](../android/app/src/main/java/com/example/campusai/data/behavior/HybridBehaviorRecognitionEngine.kt) 和 [策略](../android/app/src/main/java/com/example/campusai/data/behavior/BehaviorHybridPolicy.kt)，不能将回放简化为逐帧在两个分类结果中二选一。

1. 每个方法维护独立状态，按时间顺序消费输入，仅使用当前及过去帧。
2. 复现八帧缓冲、采样、首次可用时刻和最小调用间隔。现有策略最小间隔为 2 秒、周期条件为 3 秒；参数变更要单独记录。
3. 未调用 TSM 时，原实现可能继续使用上一次时序结果融合。记录最近更新时间和证据年龄；新增过期规则属于方法变化，不能偷偷修正原基线。
4. 复现 `COMPUTER` 的连续时序确认计数、类别融合权重、弃权及 V3.2 回退时的缓存清空。
5. 明确 Python 事件参考逻辑和 Android 当前输出的适配关系。若新增事件层，所有对照使用同一版本，不能称为已完整复现线上行为。
6. 保存候选开始、系统确认、事件结束和提醒实际发出的不同时间戳。确认延迟使用实际确认时刻，不能用回填起点。
7. 区分预测事件、冷却抑制和实际提醒。不同视频／会话之间默认清空状态；连续拼接压力测试另行定义。
8. 加入代表性轨迹验证：无触发、首次触发、重复使用旧证据、人物／ROI 丢失、回退恢复、额外类别确认、质量空档、冷却抑制及跨会话清空。
9. 增加“旧证据与新行为冲突”“刷新后反而致错”“刷新结果被拒但缓存仍旧”“固定 TTL 到期”“已调用但未采纳”“全部弃权”的轨迹，分别验证调用、采纳、缓存和覆盖率。
10. 时间一致性只用历史预测；禁止把 [L12] 完整非因果序列、真值段长度、真实边界距离和当前未调用的 TSM 输出作为门控特征。边界距离仅在事后评测分层时计算。

## 4. 五项诊断与计算方式

### D1：成本与节省上限

在固定时长、相同输入节奏、近似可加的成本模型下，记：

- `C0`：不可因跳过 TSM 消除的公共成本，包括单帧路径与必要缓存。
- `n0`：现有启发式策略的 TSM 调用次数。
- `cT`：一次 TSM 调用的平均增量成本，包含专属预处理。
- `ng`、`Cg`：新策略的调用次数与新增门控成本。

预计相对节省：

```text
C_baseline = C0 + n0 * cT
C_candidate = C0 + ng * cT + Cg
S = ((n0 - ng) * cT - Cg) / C_baseline
S_max = n0 * cT / C_baseline
```

`S_max` 假设完全取消 TSM 且无新增门控成本，是保持公共路径不变的理想成本上限，不保证质量可接受。只在成本可加近似合理时使用；动态频率、并发和 GPU 重叠下以实际测量为准。若公共路径本身也改变，应另作成本分解，不能沿用本上限。

报告 TSM 调用次数／分钟、调用次数／合法候选决策时刻、完整回放成本及相对现有策略的节省；另报相对恒调用的结果。不能只挑更昂贵的参照。测量缺失则此诊断标为待测，不输出虚构百分比。

### D2：模型互补性与致错

在有相同真值语义的样本上统计四格：两者均正确、单帧错误而时序正确、单帧正确而时序错误、两者均错误。分别按类别、来源、人物／视频及质量状态报告分母。

时序单独分类正确不代表调用融合后一定纠错，因此另报“调用后最终输出”相对“不调用并复用原有状态”的变化。事件任务采用完整轨迹重放，逐帧四格只作为解释性分析，不能直接推出事件 F1 收益。

### D2 补充：证据过期、更新与采纳

在预先锁定的年龄分箱和真实转移附近／稳定段上，输出复用错误、刷新纠错、刷新致错、额外类别漏检、拒用旧证据的覆盖损失和恢复延迟。分箱阈值只在开发数据确定，测试时不重调；真实边界只用于分层。无时间标签时该分层记为缺失。

从某个可决策时刻的相同合法状态复制两份回放，一份执行刷新、一份保留／拒用，按同一后续策略和固定观察窗口比较损失；记录 `reference_policy_id`、`horizon_ms` 与初始状态版本。这是局部反事实诊断，不是最终策略的全局 oracle。窗口和成本取舍预先指定，完整策略仍须单独从头回放。

将“发现原预测错误”“调用产生新输出”“新输出被采纳”“采纳确实改善结果”分开。报告计算后被拒比例与其成本；[L12] 已显示错误可识别不等于纠错有益，这也是本链路需要验证的问题。

### D3：事后选择机会参照

至少输出单帧、现有策略、恒调用／固定频率端点和事后选择的多预算质量曲线。恒调用结果不是质量上界。

片段无状态任务可在明确选择动作、损失和预算约束后计算相应最优参照。具有旧证据复用、计数、滞回和冷却的连续任务，逐帧选“看起来正确”的分支不保证全局最优。

只有完整求解或证明了指定状态、目标与预算下的全局最优，才标记为严格 oracle 上界。启发式搜索结果统一写作 `hindsight_reference`（事后可达参照），并记录搜索方法、预算和状态约束；不得将其作为任何触发策略的严格天花板。oracle 使用真值／未来信息，仅为诊断，不进入在线特征。

### D4：低成本信号与学习式门控

候选特征包括当时可用的最大概率、前两类间隔、熵、短期类别／概率变化、现有质量状态、时序证据年龄及过去已执行结果。是否使用单帧中间特征需单列设置和成本。标签、当前尚未调用的 TSM 输出以及未来帧均不可见。

片段任务可分别定义“调用纠错”“调用致错”“无质量变化”的监督目标，再研究成本敏感调用价值。连续任务的标签依赖参考状态或未来窗口时须说明构造方式，评价仍以完整在线回放为准。

必做对照：简单阈值与至少一种独立训练的轻量门控（如逻辑回归或小型 MLP），再比较共形信号。特征、标注和调参预算尽量一致，额外信息单独消融。

分阶段扩充对照，而不是同时实现全部论文：

| 阶段 | 对照与消融 | 要排除的解释 |
| --- | --- | --- |
| A | 原策略、无缓存／保持其他设置、固定 TTL、仅按年龄刷新 | 简单缓存规则是否已经解决问题 |
| B | 置信度／熵、[L09] 风格 JSD／预测持续性、学习门控 | 时间一致性不是新信号；状态特征是否提供额外收益 |
| C | [L07] 风格性能差／一致性风险阈值、[L10] 风格双模型路由 | 冻结后验校准／两模型路由是否已足够 |
| D | 调用门控单独、调用后采纳单独、二者结合；去掉年龄／事件状态 | 收益来自哪一个决策或状态 |

所有方法使用相同数据、模型输出、状态初始化、标注预算和统一运行点规则。若适配 [L07]／[L10] 时改变标签空间、风险、抽样单位或加入缓存，明确标为适配实验；不自动继承原论文的理论保证。[L08] 在线自适应作为有资源时的扩展，不属于首阶段硬性工作。

输出 ROC-AUC、AP、纠错／致错比例和指定调用预算下的实际质量。AP 与正例比例一同显示。没有正例或负例时 AUC 记为未定义，不填 0.5；不能凭 AUC 一项判断研究是否可行。

### D5：统计精度与独立单位

输出各划分的人物、独立会话、源视频、采集组、片段／事件和帧数，明确哪一个是可合理独立重采样的单位。

同一记录配对比较策略；以最高层独立人物／源记录重采样，保留内部事件相关性，每次重新计算总体 F1、风险和成本差。不得把帧数当作独立 n，也不能把共享人物的会话当作天然独立。

用开发预实验对目标收益、方差、组数和显著性／功效设置做敏感性分析，估计 MDE。稀有类、极少组或无有效预测时记录不可估计／精度不足。只有三个视频时不依靠 bootstrap 宣称可靠总体推断。

增加统计对象审计：真实性能、相对固定参考的性能差 [L07]、相对参考标签的一致性、集合失覆盖、被接受预测的错误比例均分别输出。参考模型错误不能被一致性掩盖。保存接受错误数和接受数；总体二者之比与会话内比例再平均分列。校准随机性下的边际保证、高概率声明和某次测试的经验比例不能互换名称。

若保留共形集合，增加集合均值／分位数大小、单元素／全集合／空集合比例和类别支持。不得照搬 [L12] 小样本阶数截断及稀有类全局回退后仍宣称标准或分类别保证；先核对所选算法在样本不足时的正确处理。若实现 [L09] 风格无标签分位数更新，只称分数或拒绝预算监测，真实错误率仍由独立真值评测。

诊断工具实现后，建议输出一个结构化汇总及必要明细；以下文件名仅是拟定产物，不表示当前已存在：

| 产物 | 主要内容 |
| --- | --- |
| `diagnostic_summary.json` | 版本、来源哈希、协议、独立样本数、D1–D5 结果、缺失与判定 |

诊断状态至少支持 `ready_to_compare`、`insufficient_data`、`measurement_missing`、`provenance_unresolved`、`no_feasible_candidate` 和 `needs_redesign`；它们是实验状态，不是生产部署批准。

必要图表：成本分解图、互补性四格图、质量—成本曲线、风险—覆盖曲线、门控 PR 曲线。数据足够再画校准样本量与跨场景曲线。所有图显示评价单位、数据协议、基准和不确定性；图名明确片段、自然连续视频、设备回放或人工拼接。

文献修订后优先增加证据年龄—复用错误曲线、稳定段／转移段对照、调用率—新结果采纳率及集合大小—覆盖曲线。每个分层显示分母；不将稀少样本的尖峰解释为稳定规律。

## 6. 运行点与继续／转向规则

开始独立校准前固定：主要风险及预算、最低覆盖与关键类别召回、可接受质量退化、最小有意义成本节省、延迟要求、候选网格和并列决胜规则。数值当前待预实验与实际目标确定，不把 AUC 0.6／F1 3 个点写成通用标准。

| 检查 | 继续条件 | 不满足时 |
| --- | --- | --- |
| 来源与数据 | 来源可说明，评价单位与划分可信 | 只做开发诊断或重建基线 |
| 成本空间 | 相对现有策略的潜在收益具有实际意义 | 弱化节能主张或调整系统问题 |
| 质量与覆盖 | 至少存在满足预设质量／覆盖要求的有收益策略 | 先改模型或任务；不靠全部弃权制造收益 |
| 信号与强对照 | 可实现门控在完整回放中有预算收益，区间足以支撑结论 | 简化方法、扩充独立数据或转向 |
| 校准可行性 | 独立校准后存在满足要求的候选 | 报告无可行点，不降低风险要求凑结果 |
| 精度 | 独立单位支持所需差异分辨能力 | 结果标为探索性，不写已证明优越 |
| 状态贡献 | 超过固定 TTL 与相同信息的无状态风险／学习门控，且收益不只来自无限弃权 | 取消新状态策略贡献，改为简化方案或经验边界研究 |
| 序列数据 | 有真实连续行为变化和可信时间标注支持过期／事件结论 | 仅保留片段机制和显式人工压力测试 |

不要求新方法同时优于所有方法的所有指标；要求在事先确定的主要约束与目标上给出可复核收益。共形方法不胜出时可以保留为对照，不能因预设叙事而隐藏负结果。

## 7. 实现前检查清单

- [ ] 确认真实可读数据位置、标签与权重来源；未知项已登记。
- [ ] 明确片段与事件实验边界、四类／五类映射及弃权分母。
- [ ] 固定独立分组，检查重复与多视角采集泄漏。
- [ ] 建立完整有状态回放与代表性轨迹验证。
- [ ] 区分确认时间、回填起点、预测事件与实际提醒。
- [ ] 测得公共路径和 TSM 增量成本；未知成本保持缺失。
- [ ] 将学习式门控列为必做对照，限制可用信息和标注预算。
- [ ] 加入固定 TTL、[L07]／[L10] 适配和时间一致性对照；原方法与适配结论分开。
- [ ] 记录证据年龄、计算／采纳／确认的不同时间及拒绝后缓存策略。
- [ ] 区分错误检测、调用收益、采纳收益和覆盖损失；检查真实连续数据是否足够。
- [ ] 固定候选与运行点选择规则，校准多重选择有对应处理。
- [ ] 记录独立样本数、区间和功效假设；不足时允许不下结论。
- [ ] 最终测试保持锁定，生成物不进入共享源码提交。
