# 面部表情遮挡训练对照实验记录（2026-10-22）

状态：**已实际运行**（train/validation 开发对照，3 个种子 × 四组）。本文区分「实际运行结果」「解释」「后续假设」，数值来自本轮真实训练与推理，不是规划或估计。

边界声明（必读）：
- 这是**开发实验**，数据为历史已暴露的 FER2013 validation 划分；本轮未使用 test 选模型/调参，但该 test 划分历史上已用于开发，日后复评也只能标为「已暴露的开发诊断」，不能称为全新独立测试集。
- 本实现是 CA-HOFT「清晰锚定 + 遮挡监督 + 冻结教师蒸馏」思路的**简化适配**，**不是** HardMix 或 CA-HOFT 的复现，不能引用其论文数值。
- FER2013 **没有人物身份**；不能做人物独立划分或按人物聚类置信区间。帧/图不等于独立个体。
- 「严重遮挡」是对固定合成掩码的压力测试，**不是**自然遮挡或外部泛化验证。

---

## 1. 目的

在同一个已有七类 ResNet-18 起点上，比较四组继续训练策略，判断结构化遮挡监督、以及「清晰图 + 遮挡图 + 冻结清晰参考教师蒸馏」是否能在保留清晰识别能力的同时改善遮挡表现。

四组（均从同一起始检查点、同一固定 train/validation 划分出发）：
- **A** 原检查点，不训练（起始参照）。
- **B** 普通继续微调，仅清晰图，无结构化遮挡。
- **C** 仅遮挡监督微调。
- **D** 清晰图 + 遮挡图监督，加冻结清晰参考教师蒸馏（KD）。

> 注意：四组能评估「完整方案」相对基线，但**不能单独分离「清晰监督」与「蒸馏」各自的贡献**（D 同时包含两者，且无「遮挡+清晰监督但无蒸馏」的中间组）。该分离列为后续组件消融（见第 8 节）。

## 3. 锁定协议（正式运行前固定，未据结果调整）

- 种子：20261022、20261023、20261024；每组每种子 5 个完整 epoch（无 smoke、无 max_batches 截断）。
- 优化器 AdamW，lr 1e-5，weight_decay 继承 1e-4，梯度裁剪 1.0；B/C/D 使用相同训练行、batch_size=64、相同 epoch 数 → **优化器更新次数完全相同（每种子 2100 次）**。
- **损失归一化（先锁定）**：监督项 = `λ_clean·CE(clean) + λ_masked·CE(masked)`，`λ_clean+λ_masked=1`（D 取 0.5/0.5；C 取 λ_clean=0；B 取 λ_masked=0）；蒸馏项 = `teacher_weight·T²·0.5·(KL_clean+KL_masked)`，`teacher_weight=0.5`、`T=2.0`。D 的双视图监督是**凸组合而非直接相加**，避免仅因求和放大梯度尺度；该口径训练前固定，未据结果回改。
- 教师：从同一起始检查点复制，`eval()` 且 `requires_grad_(False)`；只读清晰视图，不读标签或测试集。
- 遮挡：标准几何宽 0.32–0.54、高 0.15–0.27，区域为眼/嘴/随机；训练遮挡种子逐 epoch 变化、按样本确定；**验证掩码固定**（`mask_seed = seed + 1e6`），A/B/C/D 与所有 checkpoint 共用同一批验证图片与掩码。
- 额外随机擦除：将检查点配置里的 `occlusion_probability`（RandomErasing）对四组统一置 0，确保实验遮挡是唯一结构化遮挡；其余增强四组一致。
- 选择规则：固定验证掩码上的 `mean(clean_macro_f1, occluded_macro_f1)`，四组四种子完全一致；不使用 test。
- 锁定压力测试：`stress_seed = seed + 2e6`，更大遮挡框（宽 0.55–0.80、高 0.30–0.50），仅报告、**不参与选择**。

## 6. 对五个问题的回答

1. **C 相对 B 是否改善遮挡识别，代价是什么？** 是。遮挡 Macro-F1 **+0.0245**、严重压力 **+0.0304**、遮挡 Acc +0.0247，且三区域、三种子方向一致；相对 B 计算量相同（同为单视图）。清晰 Macro-F1 不仅未降、反而 +0.0054（B 相对 A 的遮挡反而略降 0.005，说明纯清晰微调会轻微侵蚀遮挡鲁棒性，C 修正了这一点）。本轮**未观察到清晰的代价**；主要代价是需构造遮挡视图与额外超参。
2. **D 相对 C 是否缓解清晰退化或进一步改善遮挡？** 基本否。D 与 C 在清晰、标准遮挡上差异在噪声内（清晰 −0.0013、遮挡 −0.0021）。D 仅在**严重压力测试**上有小而一致的优势（+0.0057 Macro-F1、+0.0031 Acc），且种子间方差更小（更稳）。由于 C 本身没有明显清晰退化，D 的「缓解退化」作用无从体现。**在 5 epoch 短程下，蒸馏的边际贡献很小。**
3. **收益是否跨种子、类别、遮挡类型稳定？** 遮挡收益跨 3 种子、3 区域、多数类别（尤其 disgust、fear、happy、surprise）方向一致且为正；效应量中等（~+2.5 个 Macro-F1 点）。清晰收益较小但多为正。**方向稳定，量级不大。**
4. **是否有类别明显受损？** 未见系统性受损类别。相对增益最大的是 disgust（0.439→0.488/0.496）与 fear（0.439→0.451/0.463）；happy/surprise 亦升。个别种子个别类有波动，但不构成稳定的类别回归。
5. **证据能支持到什么范围？** 仅支持：在本开发设置（FER2013 validation、从当前最佳七类模型起步、5 epoch、3 种子、合成遮挡）下，**结构化遮挡监督（C）相对普通微调（B）稳定提升遮挡视图 Macro-F1 约 2.5 个点且不损清晰**；**清晰参考蒸馏（D）相对 C 在短程内仅带来很小的严重遮挡鲁棒性/稳定性优势**。**不能写**：复现 CA-HOFT/HardMix、自然遮挡或外部泛化、SOTA、人物独立泛化、统计显著性的总体推断（3 种子不是 3 个数据集、无人物身份）。

## 7. 局限与未验证范围

- 单一数据集（FER2013）+ 无人物身份 → 无法人物独立划分/聚类置信区间；帧非独立。
- 历史 test 已用于开发，本轮未碰 test；任何后续 test 复评都是「已暴露开发诊断」。
- 5 epoch 短程、单起点、单损失口径；未做更长训练或超参搜索（本轮明确不做自动搜索）。
- 严重遮挡为**合成压力测试**，非自然遮挡；不代表真实前摄遮挡分布。
- 四组无法分离「清晰监督」与「蒸馏」的各自贡献。
- B/C/D 更新次数相同但计算量不同（D 约 2 倍），跨组「效率」比较需按视图数折算。
- 首次正式启动因 Windows `spawn` 重复导入脚本（缺少 `__main__` 保护）失败，仅生成空目录；已修复（加 `__main__` 守卫）、删除空目录并以新目录重跑。该失败记录保留于 `artifacts/occlusion_ablation_20261022/formal_run.log` 历史，未混入正式结果。smoke 结果单独存放、未混入。

## 8. 是否值得进入下一轮组件消融

**值得，但应是聚焦的小规模组件消融，而非扩大实验。** 理由：
- 已见稳定、可解释的信号：遮挡监督（C）是收益主驱动，跨种子/区域/类别一致；蒸馏（D）在短程边际很小但在严重遮挡上有一致小增益且更稳。
- 现有四组无法分离「清晰监督」与「蒸馏」。下一轮**最小增补**：加入 **「遮挡 + 清晰监督、无教师（C+clean, no KD）」** 一组，与 C、D 对比即可干净隔离 KD 的贡献；可固定单一全局掩码、并适当延长 epoch 观察蒸馏是否随训练变长而显现。
- 不擅自扩大：不做超参搜索、不换数据集、不动部署资产。若聚焦消融仍显示 KD 稳定增益，再考虑受试者标注数据上的独立验证。
