## 1. 目的

在同一个已有七类 ResNet-18 起点上，比较五组继续训练策略，判断结构化遮挡监督、清晰视图监督、以及冻结清晰参考教师蒸馏各自的作用。

五组（均从同一起始检查点、同一固定 train/validation 划分出发）：
- **A** 原检查点，不训练（起始参照）。
- **B** 普通继续微调，仅清晰图，无结构化遮挡。
- **C** 仅遮挡监督微调。
- **E** 清晰图 + 遮挡图监督，无教师蒸馏；与 D 使用相同的两次学生前向和监督损失。
- **D** 清晰图 + 遮挡图监督，加冻结清晰参考教师蒸馏（KD）。

归因关系：
- **E−C**：加入清晰视图监督是否有帮助。
- **D−E**：在相同双视图训练、相同学生前向次数和相同 BatchNorm 更新次数下，教师蒸馏是否有帮助。
- **D−C**：完整 D 组合相对 C 的效果，**不能**拆成蒸馏的独立贡献。

## 3. 锁定协议（正式运行前固定，未据结果调整）

- 种子：20261022、20261023、20261024；每组每种子 5 个完整 epoch（无 smoke、无 max_batches 截断）。
- 优化器 AdamW，lr 1e-5，weight_decay 继承 1e-4，梯度裁剪 1.0；B/C/E/D 使用相同训练行、batch_size=64、相同 epoch 数 → **优化器更新次数完全相同（每种子 2100 次）**。
- **损失归一化（先锁定）**：监督项 = `λ_clean·CE(clean) + λ_masked·CE(masked)`，`λ_clean+λ_masked=1`（D/E 取 0.5/0.5；C 取 λ_clean=0；B 取 λ_masked=0）；蒸馏项 = `teacher_weight·T²·0.5·(KL_clean+KL_masked)`，`teacher_weight=0.5`、`T=2.0`。
- **E 的定义**：与 D 完全相同的双视图监督项 `0.5·CE(clean)+0.5·CE(masked)`，仅移除教师与 KL 项；E 不做教师前向。
- **D/E 的双视图监督是凸组合而非直接相加**，避免仅因求和放大梯度尺度；该口径训练前固定，未据结果回改。
- 教师：从同一起始检查点复制，`eval()` 且 `requires_grad_(False)`；只读清晰视图，不读标签或测试集；仅 D 使用。
- 遮挡：标准几何宽 0.32–0.54、高 0.15–0.27，区域为眼/嘴/随机；训练遮挡种子逐 epoch 变化、按样本确定；**验证掩码固定**（`mask_seed = seed + 1e6`），A/B/C/E/D 与所有 checkpoint 共用同一批验证图片与掩码。
- 额外随机擦除：将检查点配置里的 `occlusion_probability`（RandomErasing）对五组统一置 0，确保实验遮挡是唯一结构化遮挡；其余增强五组一致。
- 选择规则：固定验证掩码上的 `mean(clean_macro_f1, occluded_macro_f1)`，五组三种子完全一致；不使用 test。
- 锁定压力测试：`stress_seed = seed + 2e6`，更大遮挡框（宽 0.55–0.80、高 0.30–0.50），仅报告、**不参与选择**。
- **E 为后补组**：A/B/C/D 已按上述协议完成，E 在同一锁定配置、同一起点、同一数据顺序规则下补跑；A/B/C/D 未重跑，超参未改。记录见 `protocol_lock_E_addendum.json`。

## 6. 对核心问题的回答

1. **C 相对 B 是否改善遮挡识别，代价是什么？** 是。标准遮挡 Macro-F1 **+0.0245**、严重压力 **+0.0304**、遮挡 Acc +0.0247，且三区域、三种子方向一致；相对 B 计算量相同（同为单视图）。清晰 Macro-F1 不仅未降、反而 +0.0054。本轮**未观察到清晰的代价**；主要代价是需构造遮挡视图与额外超参。

2. **E−C：双视图混合监督方案是否有帮助？** 在本设置下未见整体优势。标准遮挡 **−0.0109**（三种子全负），严重 −0.0054（有正有负），清晰 −0.0026（有正有负）。E 同时加入清晰视图、将遮挡 CE 权重从 1 降至 0.5，并增加学生前向与 BatchNorm 更新次数，因此这里只能比较整个方案，不能单独断言“清晰监督有害”，也不能把 D−C 归因于清晰监督或 KD 中的单一因素。

3. **D−E：在相同双视图训练下，蒸馏是否有帮助？** 有独立的小信号。标准遮挡 **+0.0087**（+0.80/+0.70/+1.12 点），严重 **+0.0111**（+0.59/+0.97/+1.76 点），三种子方向一致；清晰 +0.0013（−0.16～+0.43 点，噪声内）。E 与 D 的学生前向次数、监督损失、BatchNorm 更新次数相同，D 只多冻结教师前向和 KL 项；因此 D−E 是当前最干净的蒸馏对比。**但绝对量级只有约 1 个 Macro-F1 点，尚不足以称为稳健的方法组件。**

4. **D−C 应该怎么读？** 只能读成“完整 D 组合相对 C”。标准遮挡 −0.0021（−0.29/0.00/−0.34 点），严重 +0.0057（−0.17/+1.30/+0.57 点），并非稳定正增益。E−C 的负值与 D−E 的正值大致相互抵消，正好说明 D−C 混合了两个方向不同的因素。

5. **收益是否跨种子、类别、遮挡类型稳定？证据能支持到什么范围？** C−B 的遮挡收益跨 3 种子、3 区域、多数类别方向一致；E−C 的标准遮挡三种子全负；D−E 的标准/严重遮挡三种子全正，但只有约 1 点。当前只支持：在本开发设置（FER2013 validation、从当前最佳七类模型起步、5 epoch、3 种子、合成遮挡）下，**结构化遮挡监督（C）相对普通微调（B）稳定提升标准遮挡 Macro-F1 约 2.5 点、严重遮挡约 3.0 点且不损清晰**；**在相同双视图监督下，蒸馏（D−E）带来约 0.9–1.1 点的遮挡小增益，清晰基本持平**。**不能写**：复现 CA-HOFT/HardMix、自然遮挡或外部泛化、SOTA、人物独立泛化、统计显著性的总体推断（3 种子不是 3 个数据集、无人物身份），也不能把 D−C 写成蒸馏的独立收益。

## 7. 局限与未验证范围

- 单一数据集（FER2013）+ 无人物身份 → 无法人物独立划分/聚类置信区间；帧非独立。
- 历史 test 已用于开发，本轮未碰 test；任何后续 test 复评都是「已暴露开发诊断」。
- 5 epoch 短程、单起点、单损失口径；未做更长训练或超参搜索（本轮明确不做自动搜索）。
- 严重遮挡为**合成压力测试**，非自然遮挡；不代表真实前摄遮挡分布。
- E 为后补组，A/B/C/D 未重跑；虽然固定种子、数据顺序、掩码和选择规则，D−E 仍包含一次独立训练运行的数值随机性，不能等同于同一进程内的配对消融。
- D−E 的梯度差异来自 KL 项；教师为 eval/no-grad，不更新学生 BatchNorm。教师前向只增加计算，不改变学生 BN 状态。D−E 不能进一步区分 KL 温度/权重等超参的影响（本轮未做超参搜索）。
- 五组只覆盖 0.5/0.5 的清晰/遮挡权重；其他权重、课程式调度、不同遮挡几何未验证。
- 3 种子不是 3 个独立数据集，不构成总体显著性推断；报告的是开发集上的逐种子方向和效应量。
- E 的峰值显存记录受独立进程一次性 workspace 分配影响，不能用于跨组效率比较；墙钟时间可用于粗略参考。
- 首次正式启动因 Windows `spawn` 重复导入脚本（缺少 `__main__` 保护）失败，仅生成空目录；已修复（加 `__main__` 守卫）、删除空目录并以新目录重跑。该失败记录保留于 `artifacts/occlusion_ablation_20261022/formal_run.log` 历史，未混入正式结果。smoke 结果单独存放、未混入。

## 8. E 组之后的判断：蒸馏是否保留，下一步做什么

**归因缺口已补上：**
- E−C 表明当前双视图混合监督方案在本短程设置下未优于 C；因遮挡监督权重和 BatchNorm 更新次数也改变，不能单独识别清晰监督的作用。
- D−E 说明在相同双视图监督下，蒸馏有一个方向一致但很小的独立正信号（标准遮挡 +0.87 点、严重 +1.11 点，三种子全正；清晰基本持平）。
- D−C 是混合包，不能再用它证明或否定蒸馏。

**对蒸馏的处理：保留为候选组件，不作为已证实的主贡献。** 理由：
- D−E 的方向在三个种子上一致，值得继续；但量级只有约 1 点，且来自单一起点、5 epoch、合成掩码，不足以支撑“蒸馏是方法核心”的论文主张。
- 论文当前最稳的贡献仍是**结构化遮挡监督（C）**：相对 B 约 +2.5 点标准遮挡、+3.0 点严重遮挡，三种子/三区域方向一致。
- 不建议立刻扩大训练。若下一轮要延长日程，必须让 **C/E/D 使用相同的新训练日程一起比较**（B/A 保持对照），并沿用同一固定掩码、选择规则和逐种子报告；不能只延长 D，否则又会把日程差异混进归因。
- 若延长后 D−E 仍只有约 1 点，建议论文把蒸馏降为“可选/消融项”，方法主叙事放在遮挡监督与遮挡分区分析上；若 D−E 随训练变长而增大，再把它升为方法组件。
- 在决定是否投入更长日程前，先明确论文目标：**当前证据是可靠的开发实验信号，但还不足以支撑完整 SCI/EI 论文。** 现阶段能写的结论是“在当前 FER2013 开发设置中，结构化遮挡监督带来了约 2.5 个百分点的遮挡 Macro-F1 提升”；E/D 的结果额外提供了一个有价值的方法学结论：**不能把组合 D−C 的差异直接归因于蒸馏，控制双视图监督后蒸馏的独立收益很小。**

**建议的最小下一轮（若继续）：**
1. 预先锁定一个更长但统一的日程，C/E/D 同日程、同起点、同掩码、同选择规则；若 B 不按相同日程重跑，不将旧 B 用作公平训练预算下的效果对照。本次锁定的十 epoch 方案与独立数据准备见[下一阶段实验规划](下一阶段实验规划.md)。
2. 逐种子报告标准遮挡、严重遮挡、清晰三项，并给出 D−E 与 E−C 的配对差；不据结果改日程。
3. 只有在统一日程下 D−E 仍稳定为正且量级有意义时，才把蒸馏写入方法贡献；否则保留为消融/讨论。
4. 不在本轮追加超参搜索、换数据集或改部署资产。
