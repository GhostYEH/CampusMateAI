# Review And Release Boundaries

The skill can:

- Generate review materials.
- Generate privacy and permission checklists.
- Generate pre-submit and release-readiness reports.
- Assist with preview and upload when tools, credentials, account permission, and user authorization allow.
- Produce test account instructions when the product needs them.

The skill cannot:

- Guarantee WeChat review approval.
- Bypass WeChat review.
- Guarantee final production release.
- Forge category qualifications, payment qualifications, privacy statements, business licenses, or screenshots.
- Hide real data collection behavior.
- Put server secrets in Mini Program frontend code.
- Claim correctness without official documentation confirmation.

Before formal release, a human must confirm:

- Mini Program category and qualification.
- Privacy policy and collected data scope.
- Permission prompts and user authorization flows.
- Payment merchant qualification and backend signing security.
- Content compliance.
- Production backend, legal domains, monitoring, and rollback plan.
